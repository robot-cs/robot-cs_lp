# このレポジトリについて
## ブログ機能
Astroの機能により、content/blog下に.mdまたは.mdxファイルを作成することで、自動で新しくブログページが作成されます。
また、power appとpower automate、github workflowの併用により、アプリに記入することで自動的にブログの追加が行われるようになっています。
## ブログの追加方法（手動）
前述の通り、アプリに記入することで自動でのブログ作成が可能ですが、powerappの関係上画像の送信は（まだ）できません。
なので、その場合は自分でmdファイルを作成する必要があります。
### フロントマター
ブログ用mdファイルには、タイトルなどを定義するための値である「フロントマター」を設定する必要があります。
フロントマターは以下の3種(4種)です。
- title : タイトル。string
- created : 作成日時です。2026-05-17T10:20:00+09:00の形で入れてください。
- tags : stringのarray
オプション
- updated : 更新日時です。入れなくても大丈夫

### 追加手順
1. src/content/blogに新しくファイルを作成する
2. フロントマター、ブログ本文を書く
3. **pnpm blog**を実行する
  これはブログ一覧のファイルを自動的に更新するコマンドです。
  実行しないとブログ一覧に出てこなくなるので、必ず実行してください。
4. `main`ブランチにプッシュする
  自動でデプロイされます

## ワークフロー
以下の２つのワークフローがあります。
- deploy
  `main`ブランチにプッシュされたとき、自動的にウェブサイトの更新作業をするワークフローです。
- addblog
  アプリからブログを追加するときようです。
  一応手動でも実行できますが、あんまりやらないでください。
